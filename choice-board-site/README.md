# LIT 2000 Choice Board

A static slideshow with six pieces. The page advances automatically at a reading pace. Use **Pause** at the top right to stop automatic movement, then use the arrows at the bottom to change slides. The left and right arrow keys also work.

## Deploy on Vercel

Import the `choice-board-site` folder as the project root. Select the **Other** framework preset. No build command is needed. The included `vercel.json` serves the `dist` folder.

To preview locally, open `dist/index.html` in a browser or run `node preview-server.cjs` and visit `http://127.0.0.1:4173`.
